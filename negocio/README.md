# Carpeta del negocio

Poné acá **todo lo que describa tu negocio**: un documento, notas, un PDF con la
lista de precios, lo que tengas. No hace falta que esté prolijo.

Después, en Claude Code, escribí `/negocio`. Claude lee esta carpeta, te hace
6 preguntas y escribe `PERFIL.md`, que usa para construir cada módulo.

¿No tenés nada a mano? Usá el ejemplo: `/negocio negocio/ejemplos/mates-del-sur.md`
